- **[AI (via Adam)]** The lock-based Whisper fix above was NOT sufficient -- re-tested at `--workers 8` on the actual server (Dell PowerEdge R740, dual Xeon Gold 6240R, 96 threads, 1.5TB RAM -- discovered this run is on the same class of machine `compute_scaling.md` described for training) and the c10.dll failure rate rose to ~25-35%, scaling *with* thread count despite the import already being serialized behind `_whisper_lock`.
